## ตัวอย่างการใช้งาน

SDK ใช้ค่าเริ่มต้นชี้ไปที่ API ของ ChanomHub อยู่แล้ว จึงเรียกใช้ได้ทันทีโดยไม่ต้องตั้งค่า:

```typescript
import { createChanomhubClient } from '@chanomhub/sdk';

const client = createChanomhubClient();

// ค้นหาบทความ (GraphQL v2)
const result = await client.articles.getAllPaginated({ limit: 10 });
console.log(result.items, result.total);
```

หากต้องการชี้ไปที่ API อื่น (เช่น การพัฒนาบนเครื่อง) ส่ง config ได้:

```typescript
const client = createChanomhubClient({
  apiUrl: 'http://localhost:3000',
  cdnUrl: 'http://localhost:3000',
});
```

`createChanomhubClient` คืน client แบบสาธารณะ (อ่านข้อมูลสาธารณะ) ส่วนการเรียกที่ต้องยืนยันตัวตนใช้ `createAuthenticatedClient` ซึ่งรับ token เพิ่มเข้ามา
