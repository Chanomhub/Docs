This page is generated from `v2_schema.json`, a committed snapshot of the `/api/v2/graphql` schema. Because introspection is disabled on the production API, the snapshot is refreshed from the backend's SDL sources with `bun scripts/generate-graphql-schema.cjs` (run from the Docs repo; it reads `../backend/src/graphql/schemas/`) instead of a live introspection query. Re-run it after any backend schema change.

The same schema is served at `/api/v2/graphql` and `/api/v3/graphql`; the legacy v1 schema (adds a root-level `downloads` query) is at `/api/graphql`. Try queries against the live endpoint in the playground below.
